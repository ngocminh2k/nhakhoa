1Khởi động server local

Yêu cầu: PHP 8.x, MariaDB 10.6+ đang chạy, database nhakhoa_db đã được tạo.

1
Cấu hình biến môi trường
Sao chép file mẫu, sau đó điền thông tin kết nối MariaDB thực tế của bạn.
copy .env.example .env
# Sửa .env: DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASS
2
Khởi tạo database (schema + seed)
Truy cập endpoint này một lần để tạo toàn bộ bảng và dữ liệu mẫu.
http://localhost:8080/backend/install.php
3
Khởi động PHP built-in server
Chạy từ thư mục gốc của dự án. router.php sẽ điều hướng tất cả request.
& "C:\Users\minhd\AppData\Local\Programs\php\php.exe" -S 127.0.0.1:8080 router.php
✅ Server sẵn sàng khi trình duyệt mở http://localhost:8080 hiển thị trang chủ Nha Khoa Kim Dung.

4Đăng bài qua REST API

POST /api/v1/posts
Header: Authorization: Bearer <api_key>
Content-Type: application/json

Payload tối thiểu

{
  "title":   "Implant All-on-4 — Giải pháp phục hình toàn hàm 2026",
  "content": "<p>Nội dung bài viết có thể chứa <strong>HTML</strong> an toàn.</p>",
  "status":  "published"
}

Payload đầy đủ

{
  "external_id":     "my-system-id-001",
  "title":           "Tiêu đề bài viết",
  "excerpt":         "Tóm tắt ngắn hiển thị trên danh sách.",
  "content":         "<h2>Mục lớn</h2><p>Nội dung...</p>",
  "featured_image":  "https://example.com/anh-bai-viet.jpg",
  "status":          "published"
}

Chạy thử bằng cURL

curl -s -X POST http://localhost:8080/api/v1/posts \
  -H "Authorization: Bearer kd_live_sec_7a8f9b2c3d4e5f6a1b2c3d4e5f6a7b8c" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Bài viết test từ cURL",
    "content": "<p>Nội dung test.</p>",
    "status": "published"
  }'

Response mong đợi

✅ Tạo mới (201)
{"success":true,"data":{
  "post_id": 119,
  "action": "created",
  "slug": "bai-viet-test-tu-curl",
  "url": "/tin-tuc/bai-viet-test-tu-curl"
}}
🔄 Cập nhật idempotent (200)
{"success":true,"data":{
  "post_id": 119,
  "action": "updated",
  "slug": "bai-viet-test-tu-curl",
  "url": "/tin-tuc/bai-viet-test-tu-curl"
}}
💡 Idempotent: gửi lại cùng external_id → cập nhật bài cũ (HTTP 200), không tạo bản trùng.

Chèn hyperlink & định dạng trong content

"content": "<p>Tìm hiểu thêm về <a href='/website/trong-rang-implant.html'><strong>cấy ghép Implant</strong></a> tại Kim Dung.</p>
<p>Từ khóa <strong>bôi đậm</strong> và <em>in nghiêng</em> đều được hỗ trợ.</p>"

Gửi 100 bài hàng loạt

node scripts/send_100_posts.mjs

Kết quả kỳ vọng: 100/100 thành công trong ~1–2 giây (~11ms/bài).

Các lỗi thường gặp
